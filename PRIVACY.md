# Privacy Policy for Velocitas – AI Gmail Assistant

_Last updated: July 9, 2025_

Velocitas is a Chrome extension that enhances Gmail with AI features like email summarization, smart replies, and inbox organization.

## 1. Data Collection

Velocitas does **not** collect, store, or transmit any personal user data. All processing happens locally within the user's browser unless explicitly triggered by AI features.

## 2. AI Services

Velocitas optionally connects to [`ai.hackclub.com`](https://github.com/hackclub/ai), an experimental AI service provided by Hack Club, to generate summaries and replies.

When used:
- Selected email content is sent to the service for AI processing.
- No personally identifying data is intentionally collected or stored.
- All API usage is logged by Hack Club to prevent abuse, in accordance with their terms.
- The service is open source and intended for educational, nonprofit use.

More info: [https://github.com/hackclub/ai](https://github.com/hackclub/ai)

## 3. Storage

Velocitas uses Chrome's `storage` API only to save extension settings and preferences locally. No user data is transmitted or stored externally.

## 4. Consent

By using AI features in Velocitas, you consent to sending email content to `ai.hackclub.com` solely for the purpose of generating summaries or replies.

## 5. Changes

This policy may be updated in the future. Continued use of Velocitas after changes indicates acceptance of the revised policy.
